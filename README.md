# Wolverine Management

A responsive, static corporate website for Wolverine Management, designed for GitHub Pages.

## Stack

- Plain HTML
- Modern CSS
- Small vanilla JavaScript enhancement layer
- No framework, build step, package manager, database or server required

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

GitHub Pages can then serve the site directly from `index.html`.

## Content notes

Business positioning, portfolio, leadership, contact details and current growth items were researched from Wolverine Management's public web presence and its concept websites. The Google Business Profile link supplied for this project is included in the contact section.

The site uses external image assets from the existing Wolverine website and Unsplash, so no binary image pipeline is required for GitHub Pages.

## Files

- `index.html` — page structure, metadata and structured data
- `styles.css` — responsive visual system
- `script.js` — navigation, header state and reveal behavior
- `.nojekyll` — ensures GitHub Pages serves the static files directly
